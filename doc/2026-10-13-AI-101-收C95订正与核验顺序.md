## 2 订正 `AI-100 §4`「不套用的」

`AI-100 §4` 末条列了附录 C 缺省不套用的设备，**漏了三类**：

| 漏列 | 为什么不套 |
| --- | --- |
| `EG` + `MD`（发动机驱动的发电机） | 与往复式机器联接，另依 GB/T 2820.9 |
| 驱动机或被驱动机任一台为 `CE`、`CO` + `RE`、`PU` + `RE` 的设备 | 与往复式机器联接，另依 GB/T 6075.6 |
| 不在我方所认之列的类别（如 `FC`、`VE` 挂了振动诊断） | 附录 C 是机器振动的区界，不用于这些设备 |

另补一句 `AI-100 §4` 没写的：`TE`、`LE`、`MI`、`PU` + `RO`、`other` **确无专门标准**，≤15 kW 且三条自定线都空的，照套附录 C 下端。

完整清单改为：`CE`、`CO` + `RE` / `SC`、`PU` + `RE`、`EG` + `MD`、`BL`、`CF`、`windTurbine`、`hydroUnit`，与往复式机器联接的，以及不认的类别。

## 4 核验顺序（请回复）
