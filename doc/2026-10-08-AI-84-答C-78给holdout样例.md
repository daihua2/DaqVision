## 2 `meta_json` 里分类器相关的键

训练分类器得到的工件，`meta_json` 是一个**扁平的字符串表**（值都是字符串；下表标「JSON」的，值是一段 JSON 文本，需要再解析一次）：

| 键 | 值 | 说明 |
| --- | --- | --- |
| `format` | 字符串 | `vibration_classifier/rf@1` |
| `labels` | JSON 数组 | 类别表，按字符串排序。★**混淆矩阵的行、列都按这个顺序** |
| `features` | JSON 数组 | 用到的输入角色，如 `["temp","x_acc",…]` |
| `frames` | 数字串 | 参与训练的帧数（已剔除停机帧与缺特征帧） |
| `class_frames` | JSON 对象 | 每类帧数 |
| `stopped_excluded` / `incomplete_excluded` | 数字串 | 判为停机剔除的帧数 / 缺特征剔除的帧数 |
| `accuracy_basis` | 字符串 | 准确率依据，如「按样本分层留出 3 条样本 / 15 帧」 |
| `holdout` | JSON 对象 | 留出集评估，结构见下 |

`holdout` 的结构：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `frames` | 整数 | 留出集帧数 |
| `samples` | 整数 | 留出集样本条数（人框的段数） |
| `accuracy` | 数 | 留出集准确率，与 `Artifact.accuracy` 相同 |
| `per_class` | 对象 | 键为类别名；值为 `{precision, recall, support}`。`support` 是该类在留出集的帧数。★**分母为 0 时 `precision` / `recall` 为 `null`，不是 0**（例如留出集里没有任何一帧被判成这一类），请显示为「—」 |
| `confusion` | 二维整数数组 | 混淆矩阵，**行 = 真实类别，列 = 判成的类别**，顺序同 `labels` |

样例（我方用三类合成数据实跑一次的原样输出；数据完全可分，所以全对，**只为说明结构**）：

```json
{
  "frames": 15,
  "accuracy": 1.0,
  "per_class": {
    "不对中": {"precision": 1.0, "recall": 1.0, "support": 5},
    "不平衡": {"precision": 1.0, "recall": 1.0, "support": 5},
    "正常":   {"precision": 1.0, "recall": 1.0, "support": 5}
  },
  "confusion": [[5, 0, 0], [0, 5, 0], [0, 0, 5]],
  "samples": 3
}
```

同一次的 `labels` 为 `["不对中","不平衡","正常"]`，`accuracy_basis` 为「按样本分层留出 3 条样本 / 15 帧」。

★显示时请把 `samples` 一并带出：现场标注少时，留出集可能每类只有一两条样本，准确率看着很高却没有多少分量。
