# 铸件表面缺陷检测——成像 POC 器材清单与测试步骤

> 配套：本目录《铸件表面缺陷视觉检测可行性结论.md》
> 目的：在投入算法开发前，用最小代价验证"**缺陷能否被稳定拍清楚**"。
> 周期：1–2 周。产出：一组固定工位 + 可控打光下的合格样图，以及 **go/no-go 判定**。
> 读者：AI 视觉零基础也能照着买、照着做。

---

## 0. 先记住一句话

> **成像 POC 不是写算法，是搭一个简单拍摄台，做"打光对照实验"，找到能让缺陷跳出来的相机+镜头+光源组合。**
> 判据只有一个：**重拍出来的图，人能不能一眼看清缺陷？** 能→绿灯进算法；不能→继续调光，或判定该缺陷视觉做不了（转 NDT）。

---

## 1. POC 目标与 go/no-go 判据

| 项 | 内容 |
|---|---|
| **验证对象** | 先选 **2–3 类可见性最好的缺陷**：粘砂/夹砂、多肉/凸瘤、明显砂眼。灰毛坯件、红底漆件各取若干带缺陷样件 + 若干良品 |
| **要证明的事** | 在固定工位 + 可控打光下，这些缺陷在图像里**清晰、稳定、可重复**地显现 |
| **绿灯 (go)** | 重拍图中缺陷与背景对比明显，肉眼一眼可辨；同一缺陷多次拍摄表现一致；不同良品之间表面一致性好（背景不乱） |
| **红灯 (no-go)** | 换光、换角度后缺陷时有时无；缺陷与背景同色分不开；背景噪声（铸态麻面/漆面反光）比缺陷还显眼 → 继续调光，或该缺陷判定视觉不可做 |

---

## 2. 关键概念：几种打光方式（POC 的核心变量）

缺陷能不能拍出来，**80% 由打光决定**。必须逐一对照试：

| 打光方式 | 原理 | 对哪类缺陷有效 | 备注 |
|---|---|---|---|
| **低角度掠射光（重点★）** | 光几乎贴着表面打，凹陷投阴影、凸起被照亮 | 砂眼、缩松、多肉、磕碰、裂纹、粘砂 | **本场景首选**，凹凸缺陷的命门 |
| **暗场环形光（dark-field）** | 低角度环形，只有缺陷边缘散射进镜头，背景发暗 | 划伤、裂纹、小凹坑 | 与掠射同理，环形版 |
| **明场/高角度环形光** | 正面照亮，看颜色/纹理 | 漏喷漆、色差、大面积粘砂 | 浅凹陷拍不出 |
| **同轴光（coaxial）** | 光与镜头同轴，均匀照亮平面 | 已加工面（亮面）上的麻坑、划伤 | 第 28 页那种加工面缺陷用它 |
| **穹顶光（dome / 无影光）** | 漫反射，消除反光做基准对比 | 做"良品基准"、抑制漆面高光 | 异常检测打底用 |
| **多角度光照 / 光度立体（photometric stereo）** | 同一位置从 N 个方向分别打光各拍一张，合成出"表面法向/起伏图" | 浅缩松、浅裂纹、同色低对比缺陷 | **进阶杀手锏**，把同色缺陷的"形状"提出来。POC 后期试 |

> 一句话：**先把"低角度掠射光"试透**。它解决你样张里大部分凹凸类缺陷。同色低对比的浅缺陷，再上"多角度光照/光度立体"。

## 3. 器材清单

按"够用就好"配，分**必备**与**进阶**。品牌给的是国内工业视觉常见可选项，非指定。

### 3.1 相机（必备）

| 项 | 建议 | 说明 |
|---|---|---|
| 类型 | 工业面阵相机，**全局快门**，先用**黑白(mono)** | 黑白比彩色更利于看凹凸缺陷、灵敏度更高；颜色类缺陷(色差/漏漆)再加彩色 |
| 分辨率 | **1200 万像素起**（如 4096×3000），高难度可上 2000 万+ | 缺陷亚毫米，分辨率决定能否分辨，见第 4 节算法 |
| 接口 | GigE（千兆网，布线远）或 USB3 | POC 用 USB3 最省事 |
| 参考型号档位 | 入门：海康机器人/大恒 500–1200 万 GigE；中高：Basler ace/Balser boost、海康 2000 万 | 先租或借，别急着量产选型 |

### 3.2 镜头（必备）

| 项 | 建议 | 说明 |
|---|---|---|
| 类型 | **工业定焦镜头**，与相机靶面匹配（如 2/3"、1.1"），低畸变 | 别用单反/手机镜头 |
| 焦距 | 按工作距离和视野算（第 4 节）；常见 12/16/25/35mm | 多备 2–3 个焦距试 |
| 光圈 | 可调光圈，POC 期手动 | 景深不够就收小光圈 |
| 进阶 | 远心镜头（telecentric） | 对尺寸精度高、要消透视时才需要，POC 一般用不上 |

### 3.3 光源（必备——POC 的钱主要花这里）

> **多买几种光，是 POC 的精髓。** 光源不贵，试错价值最高。

| 光源 | 用途 | 建议 |
|---|---|---|
| **低角度环形光（暗场）** | 掠射主力 | 必备，红/白各考虑；尺寸覆盖工件 |
| **条形光 ×2~4（可调角度）** | 自由调掠射角度、做多角度光照 | 必备，配可调支架，能摆不同方位 |
| **同轴光** | 加工亮面缺陷 | 备一个 |
| **穹顶/无影光** | 良品基准、抑制反光 | 进阶，预算紧可后置 |
| 光源控制器 | 调亮度、触发频闪 | 配套 |
| 颜色 | 先用白光；红漆件可试**蓝光/绿光**增强对比（与红互补色，压底色） | 红件用蓝绿光常有奇效 |

品牌参考：乐视(Lustre)、OPT奥普特、CCS、康视达等。

### 3.4 工装与支架（必备）

| 项 | 说明 |
|---|---|
| **相机支架 / 三脚架 / 工业支臂** | 让相机**固定**，告别手持 |
| **光源支架（可调角度高度）** | 掠射角要能连续调，这是对照实验的关键 |
| **工件定位台** | 简单 V 型块/治具/转台，让工件每次摆放一致 |
| **遮光罩 / 暗箱（强烈建议）** | 挡掉车间杂散光和阳光，结果才可重复——你样张过曝/发虚就是吃了环境光的亏 |
| 黑色/哑光背景布 | 减少背景反光干扰 |

### 3.5 计算与软件（必备）

| 项 | 说明 |
|---|---|
| 一台 PC（带 USB3/千兆网口） | 采图、看图 |
| 相机厂商 SDK / 取图软件（如海康 MVS、Basler pylon、或通用 HALCON/OpenCV） | 调曝光、增益、白平衡、保存图 |
| 看图/对比工具 | 把不同打光的同一缺陷并排比 |

### 3.6 样件（必备，客户提供）

- **带缺陷样件**：每类缺陷 ≥ 5~10 件，缺陷位置已标注（客户已圈）；
- **良品件**：≥ 20~50 件（异常检测需要良品建基准）；
- 灰毛坯、红底漆**两种状态都要有**。

### 3.7 预算量级（仅供心里有数，非报价）

| 档 | 内容 | 量级 |
|---|---|---|
| 极简（借/租相机） | 一相机 + 2~3 镜头 + 3~4 种光 + 支架暗箱 | 数千元级（光源+支架为主） |
| 标准自购 | 1200–2000 万相机 + 镜头 + 多种光源 + 控制器 + 工装暗箱 | 2–5 万级 |

> POC 阶段**优先租借相机/镜头**，把钱花在**多种光源**上——光源才是要反复试的变量。

## 4. 关键计算：分辨率够不够（务必先算）

缺陷亚毫米，**先算清楚一个相机能拍多大范围、够不够细**，再决定要不要分区/多工位。

**经验法则**：最小缺陷至少要占 **3~5 个像素**才稳定可检。

**算法：**
```
每像素代表的实际尺寸  =  视野宽度(mm) ÷ 相机水平像素数
要求：最小缺陷尺寸 ÷ 每像素尺寸 ≥ 3~5 像素
```

**举例**（最小缺陷设 0.5mm，要求 5 像素）：
- 需要的分辨率：每像素 ≤ 0.5 / 5 = **0.1 mm/像素**
- 用 4096 像素宽的相机：单张能覆盖 4096 × 0.1 = **约 410mm 宽**
- 若工件某个面 300mm，一张够；若整个壳体要 360° 全覆盖 → **必然要多工位/多相机/转台**

> 结论先行：**复杂壳体一台相机拍不全**。POC 阶段先验证"单个缺陷面拍得清"，全覆盖的工位数按这个算法和方案书第 10 页的"路数×切片×节拍"预算另算。

## 5. 测试步骤：打光对照实验怎么做

核心是一张**对照矩阵**：固定其它变量，**只变一个变量**，逐一拍、逐一比。

### 步骤 0：搭台（半天）
1. 相机上支架，对准样件缺陷区，调好工作距离/对焦。
2. 工件放定位台，记录摆放姿态。
3. 套暗箱/遮光，排除环境光。

### 步骤 1：定基线
- 选 1 件**最典型的缺陷样件**（如第 2 页粘砂）。
- 先用一种光（低角度环形）拍一张，调曝光/增益到不过曝不过暗，存为基线。

### 步骤 2：光源种类对照（最重要）
保持相机、工件、距离不变，**只换光源种类**，每种各拍一张：

| 实验号 | 光源 | 角度 | 颜色 | 结果（缺陷清晰度 1–5） | 备注 |
|---|---|---|---|---|---|
| L1 | 低角度环形(暗场) | ~10° | 白 | | |
| L2 | 条形光单侧 | ~15° | 白 | | |
| L3 | 条形光单侧 | ~30° | 白 | | |
| L4 | 条形光单侧 | ~60° | 白 | | |
| L5 | 同轴光 | 0° | 白 | | |
| L6 | 穹顶/无影光 | — | 白 | | |
| L7 | 低角度 | ~10° | 蓝/绿（红件用） | | |

### 步骤 3：角度对照
对效果最好的那种光，**只变掠射角度**（5°/10°/20°/30°/45°…），找出缺陷最"跳"的角度。

### 步骤 4：方位对照（为多角度光照铺垫）
光从**上/下/左/右**四个方位分别打、各拍一张。观察：
- 有没有哪个方位缺陷消失？（说明单光不够，需多角度合成）
- 为后续**光度立体**确认要几个方位。

### 步骤 5：颜色对照（针对红底漆件）
红件用**白/蓝/绿**光各拍，看哪种最能压住红底色、凸显缺陷。

### 步骤 6：覆盖两种状态 + 多样件
把步骤 2–5 的最优组合，分别在：
- 灰毛坯件、红底漆件；
- 每类缺陷各 5~10 件、若干良品；
- 上重复拍摄，验证**一致性与重复性**（同一缺陷多拍几次还稳不稳）。

### 步骤 7：进阶（可选）——光度立体
对"同色低对比"的浅缺陷（浅缩松/浅裂纹），用条形光从 ≥3 个方位各拍一张，离线合成表面法向/起伏图，看缺陷能否被"形状化"提出来。

## 6. 记录与判读

每张图记录：**光源/角度/颜色/曝光/工件状态/缺陷类型/清晰度评分(1–5)**。

| 缺陷类型 | 工件状态 | 最佳光源组合 | 最佳清晰度 | go/no-go |
|---|---|---|---|---|
| 粘砂 | 灰毛坯 | | | |
| 多肉 | 灰毛坯 | | | |
| 砂眼 | 红底漆 | | | |
| 浅缩松 | 红底漆 | | | |
| … | | | | |

**判读原则：**
- 某缺陷在某组合下**稳定 ≥4 分** → 该缺陷绿灯，记录最佳成像方案；
- 怎么调都 ≤2 分、时有时无 → 该缺陷红灯，标注"需 3D/光度立体"或"视觉不可做，转 NDT"。

## 7. POC 交付物（结束时应拿出）

1. **成像方案表**：每类缺陷 × 每种工件状态，对应的最佳相机/镜头/光源/角度/颜色组合。
2. **样图集**：固定工位、可控打光下重拍的合格图（按缺陷分类，含良品基准图），可直接用于后续算法训练/异常检测建模。
3. **分辨率与覆盖结论**：单相机能覆盖多大面、整件需要几个工位/相机。
4. **go/no-go 清单**：哪些缺陷可做、哪些需进阶手段、哪些超视觉范围。
5. **下一步建议**：进入计划阶段 5（无监督异常检测）的输入条件是否具备。

---

## 8. 避坑清单

- ❌ 用手机/手持拍 → 必须固定工位、可控光、套暗箱（你那批样张的教训）。
- ❌ 一上来追求拍全部缺陷类型 → 先做 2–3 类可见性最好的。
- ❌ 只试一种光就下结论 → 打光对照实验是 POC 的核心，必须逐一比。
- ❌ 拿手机样张训练算法 → 那批图只能确认缺陷种类，不能评估精度、不能训练。
- ❌ 忽视背景一致性 → 铸态麻面/漆面反光会变成"假缺陷"，良品基准要先稳。
- ❌ 不算分辨率就买相机 → 先按第 4 节算 px/mm，再定相机和工位数。
