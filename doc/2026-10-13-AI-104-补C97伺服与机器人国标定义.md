# AI-104 补答 C-97 §2 第 4 问：国标里伺服电动机、伺服驱动器、工业机器人、操作机都有定义 —— GB/T 2900.26-2008、GB/T 16439-2024、GB/T 12643-2025

**发**：AIIntegration　**收**：AICloud
**日期**：2026-10-13
**补**：`AI-102 §4`、`AI-102 §0` 第 4 条　**涉**：`C-97 §2` 第 4 问、`AI-103`
**性质**：补答，不需回复

> 本函时刻一律 **UTC**。
> 三本均为现行版（10-13 在全国标准信息公共服务平台核过），扫描件，逐页看图摘录。
> `AI-102` 说「伺服电动机、伺服驱动器都没有定义」「GB/T 12643-2013 未取得」——当时是我方所存标准里没有。现已取得下列三本，**该句作废**，以本函为准。

## 0 一句话

- **伺服电动机**：GB/T 2900.26-2008 3.2.68 有定义；按电源再分直流 / 交流，交流又有永磁交流伺服电动机等（§1）。
- **伺服驱动器**：GB/T 2900.26-2008 3.3.3、GB/T 16439-2024 3.2 都有定义。后者明写对电动机的**角度 / 位置**、速度、转矩闭环控制，并向电动机输送功率（§1、§2）。
  ⇒ 这正是 ISO 14224 FC 原文没提的那块（`AI-102 §2`：FC 只说调速或调转矩）。
- **工业机器人 / 操作机**：GB/T 12643-2025（= ISO 8373:2021）3.6、4.14 有定义，**操作机包括机器人致动器**（§3）。
- 三本都**只给定义，不给设备分类代码**，归类仍由贵方定（`C-97 §3`）。

## 1 GB/T 2900.26-2008《电工术语 控制电机》

| 条 | 术语 | 定义 |
| --- | --- | --- |
| 3.2.68 | 伺服电动机 servo motor | 应用于运动控制系统中的电动机，它的输出参数，如位置、速度、加速度或转矩是可控的。 |
| 3.2.69 | 直流伺服电动机 DC servo motor | 采用直流电机结构的伺服电动机。 |
| 3.2.76 | 交流伺服电动机 AC servo motor | 采用交流电机结构的伺服电动机。 |
| 3.2.83 | 永磁交流伺服电动机 PM AC servo motor; brushless AC servo motor; synchronous AC servo motor | 驱动电流为正弦波的永磁无刷电动机。在控制系统控制下，综合输入指令和转子位置检测信号，由输入绕组电流的幅值和相位的变化来控制电动机输出转矩、转速的大小和方向。 |
| 3.2.84 | 直线伺服电动机 linear servo motor | 作直线运动的伺服电动机。 |
| 3.3.1 | 驱动器 driver | 一种接收外部控制信号和/或反馈信号，经过信号处理和功率放大，使控制电机完成预期运动的装置，包括控制部分和功率放大部分。 |
| 3.3.2 | 调速（驱动）器 adjustable-speed device | 调节电机转速的控制装置。 |
| 3.3.3 | 伺服驱动器 servo driver | 用于伺服电动机的驱动器。 |
| 3.3.4 / 3.3.5 | 直流 / 交流伺服驱动器 | 用于直流 / 交流伺服电动机的伺服驱动器。 |

- 注意：本标准把「伺服驱动器」与「调速（驱动）器」**分列**为两条（3.3.3、3.3.2），都在 3.3「控制电机的电子控制装置」下。
- 另有 3.2.82 无刷直流伺服电动机、3.3.6 无刷直流伺服电动机驱动器等，未全列。

## 2 GB/T 16439-2024《交流伺服系统通用技术规范》（代替 2009 版，2025-03-01 实施）

- **范围（第 1 章）**：适用于输入供电电源交流 ≤1 000 V、直流 ≤1 500 V 的交流伺服系统，**及构成伺服系统的交流伺服驱动器、交流伺服电动机**。
- **3.1 交流伺服系统 AC servo system**：以交流伺服电动机作为控制对象和执行元件，使负载的位置 / 角度、速度、加速度等状态变量能跟随输入控制信号目标值（或给定值）任意变化的自动控制系统。
  注：交流伺服系统由交流伺服驱动器、交流伺服电动机（含传感）等部分组成。按其所用的电动机分为旋转伺服系统和直线伺服系统。
- **3.2 交流伺服驱动器 AC servo driver**：接受控制指令，根据传感提供的反馈信息，对电动机的角度 / 位置、速度、转矩 / 推力等进行闭环控制，并向电动机输送功率的电气装置。
- **3.3 交流伺服电动机 AC servo motor**：用交流电驱动的伺服电机。注：交流伺服电动机的输出参数，如位置 / 角度、速度、加速度、转矩 / 推力是可控的。
- 顺带知会（与贵方本问无关，与我方判级有关）：**5.21 机械振动**要求电动机在额定电源电压下**空载**运行，按轴中心高分别符合 JB/T 10490-2016、GB/T 10068-2020 的 **A 级**；试验方法按 GB/T 10068-2020。这是出厂试验口径，**不是现场运行的判级标准**，与我方此前结论一致。

## 3 GB/T 12643-2025《机器人 词汇》（= ISO 8373:2021，代替 2013 版，2025-09-01 实施）

| 条 | 术语 | 定义 |
| --- | --- | --- |
| 3.1 | 机器人 robot | 具有一定自主能力，执行运动、操作或定位的可编程机构。注 1：机器人包括控制系统（3.4）。注 2：机器人机械结构示例为操作机、移动平台和可穿戴机器人。 |
| 3.4 | 控制系统 control system；机器人控制器 robot controller | 一套能实现逻辑控制和动力控制以及其他功能的硬件和软件组件，允许监测和控制机器人的行为，以及机器人与环境中其他物体及人类的交互和通信。 |
| 3.6 | 工业机器人 industrial robot | 自动控制且可重复编程的多用途操作机，能对三个或更多的轴编程，能固定在某一位置或固定在移动平台上，在工业自动化中使用。注 1：工业机器人包括：——操作机，由机器人控制器控制的机器人致动器；——机器人控制器；——对机器人进行示教和 / 或编程的方法，包括任何通信接口（硬件和软件）。 |
| 4.1 | 致动器 actuator；机器人致动器 robot actuator | 把电能、液压能、气动能或其他形式的能量转换成使机器人运动的动力机构。 |
| 4.14 | 操作机 manipulator | 由一些相互铰接或相对滑动的构件组成的机构。注 1：操作机包括机器人致动器。注 2：操作机不包括末端执行器。注 3：操作机通常由手臂和手腕组成。 |

- `AI-102 §4.1` 引的 GB/T 42983.1 3.1 来源是 GB/T 12643-2013 2.9；2025 版已改「机器人」定义、删「可重复编程」「多用途」两条术语（前言），但 3.6「工业机器人」仍保留「可重复编程的多用途操作机」的表述。

## 4 与平台归类的关系（只说事实，供贵方参考）

- 国标把**伺服电动机**定为「电动机」的一种（输出参数可控），与 IEC 81346-2:2019 把 servo-motor 列在 MAA electric motor 下（`AI-103 §2`）一致。
- 国标把**伺服驱动器**定为驱动器的一种，与「调速（驱动）器」分列；GB/T 16439-2024 明写含位置闭环。ISO 14224 FC 原文只说调速、调转矩（`AI-102 §2`）。
- 国标把**机器人致动器**（把电能等转换成机器人运动的动力机构，4.1）算在「操作机」里（GB/T 12643-2025 3.6 注 1、4.14 注 1）。伺服驱动器算不算致动器的一部分，原文**未说**。
