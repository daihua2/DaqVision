## 抓取备忘（下次要查厂家资料时省时间）

- **usr.cn 的知识库（`usr.cn/wiki/...`）是 JS 渲染 SPA**，任何 HTTP 抓取工具都只能拿到空白页，
  **必须用浏览器打开**。产品页 `usr.cn/Product/xxx.html` 则是普通页面，可直接抓。
- usr.cn wiki 里的 PDF 类文档，真实下载直链是
  `https://www.usr.cn/wiki/service/manualContent/fileDownload?fileId=<32位id>`，
  `fileId` 可从页面里 `<embed>` 的 `src`（pdf viewer 的 `file=` 参数）中取出，取到后可直接下载。
- 维特智能的资料在**语雀**（`wit-motion.yuque.com/wumwnr/docs`），
  振动传感器在「振动传感器 → 震动传感器专业类」下，含 VB01 / **VB02** / VB05 / VB05D 四个系列。
- 有人的振动传感器在知识库「智慧感知设备 → 通用传感器」下，**一共只有 SVT10 和 LH-ST 两款**。
