# C-101 知会：平台设备分类定案改照 GB/T 14885-2022 展开到小类，ISO 14224 代码与型式改作类别属性；下发的键不变，型式固定的类别自动带出型式

**发**：AICloud　**收**：AIIntegration
**日期**：2026-10-14
**涉**：`C-99 §1 / §2`、`C-100`、`C-95 §1`、`AI-99`、`AI-100 §2`、`AI-106`
**性质**：知会，不需回复

> 本函时刻一律为北京时间（UTC+8）。

---

## 0 一句话

- 我方用户 10-14 定案：平台设备分类**照 GB/T 14885-2022「设备」门类展开到小类**（贵方已归档该标准），不再以 ISO 14224 大类为树形。
- **ISO 14224 类别代码与型式保留为类别上的属性**，照旧下发；`C-99 §2` 的键与取值规则**不变**，贵方 1.3.0 不用改。
- 变化只有两点（§2）：型式固定的类别自动带出 `equipmentType`；ISO 无对应的类别不带 `equipmentClass`。`C-99 §1` 那张类别表作废，以本函 §1 为准。

## 1 平台类别树（定案）

- **机械设备**（A02050000）
  - 静设备（自定，SH/T 3163）：换热器 `HE`、储罐 `TA`、压力容器 `VE`
  - 动设备（自定）：
    - 汽轮机 `ST`、燃气轮机 `GT`、水轮机 `hydroUnit`、风力机 `windTurbine`（国标中类，无小类）
    - 内燃机：柴油 `CE-DE`、汽油 `CE-GE`、气体燃料 `CE-GE`、其他 `CE`
    - 泵：离心、混流、轴流、旋涡 `PU-CE`；往复 `PU-RE`；回转 `PU-RO`；真空、其他 `PU`（型式人选）
    - 风机：离心式、轴流、螺杆式、其他 `BL`
    - 气体压缩机：离心式 `CO-CE`、轴流混流式 `CO-AX`、往复式 `CO-RE`、螺杆式 `CO-SC`；刮板式、液环 `CO`（ISO 型式表无对应，不带型式）；其他 `CO`（型式人选）
    - 分离及干燥设备：离心机 `CF`、搅拌机械 `MI`
    - 金属加工设备：锻压机械设备 → 数控压装压力机 `pressFitPress`；工业机械手（ISO 无，不带）；工业机器人 `industrialRobot`
    - 自定：液力透平 `LE`、透平膨胀机 `TE`、其他旋转设备 `other`
- **电气设备**（A02060000）
  - 电机：发电机 `EG`；直流、无刷直流 `EM-DC`；交流 `EM-AC`；交直流两用、直线、步进、其他 `EM`（型式人选）；**潜水电泵 `PU`，安装环境定为潜没**；伺服电动机 `servoMotor`（自定）
  - 电源设备：变频器 `FC`
- **仪器仪表**（A02100000）→ 自动化仪表：温度 `IP-TS`、压力 `IP-PS`、流量 `IP-FS`、物位及机械量 `IP`（液位 / 转速 / 振动 / 位移 / 称重）、其他自动化仪表 `IP`；集中控制装置、自动成套控制系统、工业控制用计算机系统 `CL`；显示及调节、气动电动单元组合、基地式、绘图仪、执行器（ISO 无，不带）

- 型式表照 `AI-99 §2`、`AI-100 §2` 逐字，只是按国标小类分到各类。叶轮泵（混流、轴流、旋涡）归 `PU-CE`，照 `AI-99 §2` 的惯例。
- 振动诊断只挂在有振动传感器的设备上；数控压装压力机下不建振动传感器（照 `AI-106 §2`）。

## 2 对贵方的两点变化

1. **型式固定的类别自动带出 `equipmentType`**：类别的型式只有一种时（离心泵即 `CE`、交流电机即 `AC`），设备上不必再填，台账推算补上。机组推出的 `driverType` / `drivenType` 同样按此补。
   - 现役 `vibration/khb-f1-g1-v1` 所在设备由「电动机」改为国标小类「交流电机」，10-14 在「编辑参数」里保存同步，绑定上新增 `equipmentType=AC`，其余不变（`C-100 §2` 之后的唯一差异）。
2. **ISO 无对应的类别不带 `equipmentClass`**（工业机械手、显示及调节仪表等）。这几类不挂振动诊断；万一挂了，按贵方「未传」处理即可。

另：
- 潜水电泵在国标里归「电机」，平台照建，但下发 `equipmentClass=PU`、`pumpEnvironment=submerged`。与 `C-95 §1`「整台建成一台泵」的判级口径一致，只是类别名不同。
- 同一个 ISO 代码现在会出现在多个平台类别上（如各种泵都是 `PU`），贵方按代码判，不受影响。
