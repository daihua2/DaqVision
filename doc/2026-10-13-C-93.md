## 0 一句话

- 平台现在的设备类别树混用了两把尺子：一是**设备是什么**，二是**适用哪份振动评价标准**。
  最明显的是「旋转设备 → 工业机器 → 电动机」。「工业机器」是 GB/T 6075.3 划适用范围的用语，不是设备种类。
  `C-92` 补的 5 类沿用了同一错误，例如「往复式机器」把往复压缩机、往复泵、内燃机混成了一类。
- 我方用户 10-13 定：**设备分类尽快与贵方商定，每一条都要有 ISO 或国标依据**。贵方手上有全套标准原文，我方只有公开资料。
- 我方提议：**类别 = ISO 14224:2016 的设备类别（equipment class），型式 = 该类别下 ISO 14224 的型式（type）**。
  判级用哪份标准、机器分组等由「类别 + 型式 + 铭牌量」推出，不再决定树的形状（§1、§2）。
- `C-92 §1`（设备类型对照表、§1.3 的 `other`）**暂缓**，以本函商定结果为准。`C-92 §2 ~ §4`（额定功率与转速、删机器分组「不适用」、B 区蓝色）照旧有效。

## 1 原则（请贵方确认或纠正）

1. **类别只回答「这是什么设备」**，取 ISO 14224:2016 附录 A 的设备类别与代码。
   该标准还有对应国标 GB/T 20172-2006，但等同采用的是 ISO 14224:1999，2024-08 复审结论为「修订」。所以以 2016 版为准，国标作对照。
2. **型式（离心 / 往复 / 螺杆……）是类别下的一项属性**，取值用 ISO 14224 该类别型式表的代码。
3. **振动评价标准（GB/T 6075.x / GB/T 41850.x / GB/T 7777 / GB/T 35854 等）不进类别树**，由贵方按类别、型式、铭牌量判（同 `AI-96 §1`）。
4. **评价参数挂在需要它的类别上**：轴中心高只在电动机上，泵类别只在泵上。机器分组、支承方式挂在哪些类别上，按贵方所依标准定（§3 第 4 问）。
5. **ISO 14224 未覆盖的设备**（该标准只管石油、石化与天然气工业，没有风电、水电、通用生产机械）：
   按「扩展」标明并给出所依标准。扩展类的依据请贵方定，§3 第 3 问给了一个候选。

## 3 请贵方对照原文答

1. **ISO 14224:2016 附录 A 的设备类别表**：表号，各大类下的全部类别与代码。
   重点核三点：电动机 EM 在「旋转」还是「电气」大类下（公开资料显示在旋转下）；2016 版是否新增了类别；变频器 FC、现场仪表 IP 等的归属。
2. **上表各类的型式表**：型式名称与代码，以附录 A 各类别的表为准。泵的「旋转动力泵 / 容积泵」怎么对应 ISO 的型式，也请一并说明。
3. **ISO 14224 未覆盖的设备怎么分**：风电机组、水轮机组、通用生产机械（如数控压装压力机）。
   候选：IEC 81346-2:2019（国标 GB/T 5094.2）的对象类别。贵方若有更合适的依据，请给出。
4. **评价参数挂在哪些类别上**：机器分组、支承方式、轴中心高、泵类别各适用哪些「类别 + 型式」，给出所依标准的条款。
5. **兜底类**：要不要保留「其他」。若保留，按 `C-92 §1.3` 视为「无适用标准、采用自定门槛」。
6. **传给模块的键**：我方提议把 `AI-96 §3` 的 `machineType`（12 个自拟取值）改为两项 `machine` 层参数，**直接用 ISO 代码**：
   - `equipmentClass`：类别代码，如 `EM`、`CO`、`PU`；
   - `equipmentType`：型式代码，如 `AC`、`SC`、`RE`；
   - 扩展类的代码由双方在本轮商定。
   这样双方都不必维护一张自拟词表与标准之间的对照。贵方若仍要 `machineType`，请说明理由，平台可以由 ISO 代码推出。
   1.3.0 尚未部署，现在改代价最小。
