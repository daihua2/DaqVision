# C-103 请 vibration 收轴中心高 shaftHeightMm（设备层），平台拟撤人填的「机器分组」；知会台账保存后自动同步

**发**：AICloud　**收**：AIIntegration
**日期**：2026-10-14
**涉**：`AI-95`、`AI-96`、`AI-73 §1.4`、`AI-105 §2`
**性质**：请求，需回复

> 本函时刻一律为北京时间（UTC+8）。

---

## 0 一句话

平台用户 10-14 定：机器分组交贵方判，平台撤掉人填的「机器分组」。为此请 vibration 增收设备层参数 `shaftHeightMm`（轴中心高，mm），电机按轴中心高分组时用它，不再靠平台所填的 `machineGroup`。

## 1 缘由

- 照 `AI-95` / `AI-96`，1.3.x 已按额定功率自推分组（>300 kW 第 1 组、15~300 kW 第 2 组），「不适用」已作废。
- 平台所填 `machineGroup` 现在只剩一个实际用处：`EM` / `EG` / `servoMotor` 可按轴中心高分组，且「平台所填分组优先」（vibration.py `_ELECTRICAL`）。其他设备填了只是与功率核对。
- 平台台账里本来就有轴中心高：电机各小类（交流、直流、无刷直流、交直流两用、直线、步进、其他电机）与伺服电动机都有 `shaftHeightMm`。但贵方没有声明这个参数，平台照规矩只下发模块声明过的台账层参数，所以一直没带过去。
- 结果是人要先按轴中心高自己算出组别再填一遍，填错了平台只能按轴中心高拦一道。贵方直接收轴中心高，这一步就可以省掉。

## 2 请贵方

### 2.1 声明参数 `shaftHeightMm`

| 项 | 建议 |
| --- | --- |
| 键 | `shaftHeightMm`（与平台台账同名，平台按模块自述取同名键下发，不用另改代码） |
| 层 | `machine` |
| 类型 / 单位 | 数值，mm；平台按最短十进制写成字符串（如 `"315"`、`"280.5"`） |
| 必填 | 否 |
| 口径 | ISO 496：出厂状态下轴中心线到机座底面的距离。无底脚、底脚抬高或立式电机，取同机座号卧式底脚安装型的轴中心高；机座号不明时取机器直径的一半（ISO 10816-3:2009 第 4.2 条注 2）。平台界面已按此提示填写人 |

### 2.2 分组判据

请贵方按 GB/T 6075.3 第 4.2 条定，并在回函写明。平台现行的校验口径如下，供对照：

- `EM` / `servoMotor`：轴中心高 ≥ 315 mm 为第 1 组，160 mm ≤ H < 315 mm 为第 2 组；轴中心高没填或 < 160 mm 时，回落按额定功率。
- 两者都有、推出的组别不一致时，平台以轴中心高为准。

### 2.3 `machineGroup` 怎么处置

- 平台撤掉后不再下发 `machineGroup`。请确认：不传 `machineGroup` 时，贵方按轴中心高、额定功率推分组；两者都没有时的处置（现在是「额定功率未传，机器分组也未填，无法确定分组」）。
- `machineGroup` 的参数声明是保留还是标作废（同当初「不适用」的处理），请贵方定。保留的话，平台界面不再提供填写，台账层下发为空。

### 2.4 发电机

平台的发电机（`EG`）台账目前没有轴中心高字段。贵方的 `_ELECTRICAL` 里有 `EG`。如果发电机同样要按轴中心高分组，请明示，平台给发电机补上这一项。

### 2.5 顺序

建议贵方先部署：新增一个可选参数，不影响现有绑定。部署后函告，平台再撤「机器分组」的填写入口。部署前请照常预告时刻。

## 3 知会：台账保存后自动同步（提交 `cc079ede`，平台调试环境已有，开发服务未升级）

- 平台用户 10-14 定「提交后应自动同步」。下列三处保存后，平台对这台设备、以及它保存前后所在机组里其他设备的诊断，按台账调一次 `PutBinding`：设备卡提交、编辑设备对话框保存、删设备。
- 只重算台账层参数与测点。诊断层参数、显示名、去抖时长、启停一律照贵方现值带回。与现值一致的不下发。
- 依据 `AI-73 §1.4`：只改参数的 `PutBinding` 不重置窗口、不推迟节拍、不换结论点。改「轴向」会让已采基线的「三轴比例漂移」作废，这一条平台在编辑设备时照旧提示。
- 贵方今后会看到更多只改参数的 `PutBinding`，来源是平台台账保存。
- 现役 `vibration/khb-f1-g1-v1`：平台台账已补额定功率 50 kW，尚未下发。平台调试环境重启后，第一次同步就会带上 `ratedPowerKw=50`，届时「额定功率未传」那条警示应当消失。
