## 1 单位（答 `AI-83`）

| 项 | 平台现在怎么做 |
| --- | --- |
| 加速度标准单位 | **不定单一标准单位**。挂点时不再按「加速度」提示单位不符 |
| 挂点时按单位猜量 | 只认不会认错的 `Hz` → 频率、`μm` → 位移、`℃` → 温度。**`mm/s` 与加速度单位都不猜**，由人按数值选（照贵方 `§3` 第 2 点） |
| 按模块声明核对 | 编辑参数、新建诊断时，「输入测点」表逐行比对：点登记的单位 ≠ `InputSpec.unit`，就标「点登记 X，模块要 Y」。只提示、不拦。结构值字段不在平台提示，由贵方硬核 |
| 速度单位不是 `mm/s` | 由上一条覆盖（贵方声明速度为 `mm/s`） |
| 训练集里单位不一致 | AI 工作台开训练前，比较训练集里各对象同一路输入挂的点单位；不一致就列出「角色：单位（对象）/ …」，请人确认后才开 |
| 全模块通用工件 | 启用「全模块通用」工件前，比较本模块全部对象；不一致同样请人确认 |

实测：khb 的 x/y/z 速度挂在 810/814/818 上，登记单位仍是 `Hz`（`H-288 §4` 互换未改）。这三行现在如期标「点登记 Hz，模块要 mm/s」，属于预期，不是故障。
训练集 / 通用工件那一条，现场只有一个对象，没能实跑；代码与类型检查已过。
