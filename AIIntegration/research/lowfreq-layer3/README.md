## 2 ★v5 的模型与训练集为什么不能用（四条，每条都有出处）

### 2.1 准确率是**训练集自测**得出的

`v5/backend/services/single_frame_models.py:105-106`：

```python
model.fit(X, y)
metadata["accuracy"] = float(accuracy_score(y, model.predict(X)))
```

**没有留出集、没有交叉验证** —— 拿训练数据自己考自己。
实测：`local_data/models/` 下 **71 个模型元数据，`accuracy` 全部等于 `1.0`**。
这不是"模型很准"，是这个数字**不携带任何泛化信息**。

### 2.2 类别极度不平衡，少数类只有个位数

`local_data/labeled_data.json`（7619 条标注，2026-08-16 ~ 09-05）标签分布：

| 标签 | 条数 | |
| --- | --- | --- |
| 不平衡 | 4294 | ← 与下一行合计 **7289 条 = 95.7%** |
| 不平衡模型知识库 | 2995 | |
| 0818开机 | 173 | ★这不是故障类，是操作备注 |
| 关机 | 87 | ★同上 |
| **正常** | **22** | |
| 机械松动 | 14 | |
| 0901开机 | 13 | ★同上 |
| 不对中 | 11 | |
| 轴承故障 | 8 | |
| 故障 | 2 | |

⇒ **一个"永远答不平衡"的模型，在这份数据上也能得 ~96% 的准确率。**
配上 §2.1 的训练集自测，`accuracy=1.0` 就是必然结果（随机森林记得住 7619 条）。

★另注：**标签字段里混进了操作备注**（开机/关机）与一个"知识库"标记。
标签体系本身需要重建，不只是样本不够。

### 2.3 实际跑的算法不是 `C-40` 所述的那三个

`C-40 §5.4` 说"三个模型（决策树 / SVM / 小神经网络）"。实测 71 个模型的元数据：
**70 个是 `RandomForest fallback`、1 个 `RandomForest`** —— 那三个选项实际都没生效，全落到了回退分支。
⇒ 若按"移植那三个模型"去做，会发现现场根本没有它们的产物。

### 2.4 底层数据本身无诊断意义

`C-40 §4` 已实测证明：v1 那组点被**两路交错写入**（Node-RED 通路一的均匀随机数 + v5 仿真器的物理模型），
现役基线实质是随机数的上界。v5 这份标注集采自同期同源的数据
（传感器 `76579465754956770269` 占 7240 条）。

⇒ **拿它训出来的分类器，学到的是随机数的形状，不是故障的形状。**

## 3 我方要补的三件（v5 没有、而第③层必须有）

1. **留出集或交叉验证**，并报**每类**的精确率/召回率与**混淆矩阵** —— 只报 accuracy 在不平衡数据上是误导。
2. **类别不平衡的处置**（分层抽样、类权重，或明确拒绝在少数类样本不足时出结论）。
   ★宁可落 `INSUFFICIENT_SAMPLES` 坏码，也不出一个"永远答多数类"的结论。
3. **最小样本量门槛**：每类样本低于门槛就**训练失败并说清**，照低频振动第②层采基线那条既有规矩
   （`MIN_BASELINE_FRAMES`，一条都匹配不上就当场失败）。

## 4 契约影响：★**域自述变，契约不动**

| 改动 | 要不要动 `aiintegration.proto` |
| --- | --- |
| `InputSpec` 从 4 个角色增到 13 个 | ❌ 不动 —— 角色是**域自述**，前端按 `DomainInfo.inputs` 渲染 |
| `outputs` 增加"故障类别 / 置信度" | ❌ 不动 —— 同上，按 `param_specs`/`outputs` 渲染的纪律 |
| 工件要带每类指标与混淆矩阵 | ❌ 先用 `Artifact.meta_json` 承载，**不为它升版** |

⇒ 与 `README §11.4`「契约没动，但域的自述变了」是同一形态。**第③层不需要契约加法。**
★这也意味着：第③层可以与界面重构**并行推进，互不阻塞**。

## 5 建议的次序

1. **等 `C-40 §4.4` 数据源落定**（v1 只留有物理模型的那一路）。这是第②层验收与第③层**共同的前置**。
2. 做 `C-40 §5.3` 的第②层受控对照（切故障 → 看四项是否显著上升、比例漂移方向是否可分）。
3. ★**同一批受控数据顺带给第③层攒标注** —— 切故障时本来就知道当前是哪一类，
   标注是"免费"的，且**标签可信**（不是人事后看曲线猜的）。
4. 样本量达到每类门槛后训第③层，按 §3 的三件出评估报告。

★**不建议**跳过第 1 步直接训 —— 那只会复制 v5 已经踩过的坑：在没有诊断意义的数据上得到一个 `accuracy=1.0` 的模型。
