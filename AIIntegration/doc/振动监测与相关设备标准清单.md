## 0 要紧的发现

1. ★**ISO 20816 的国标版是 GB/T 41850 系列**，已出 .1 / .2 / .5 / .8 / .9；**站上没有 .3**。
   ⇒ 判级依 GB/T 6075.3-2011 的决定（[ISO20816-3机组分类与限值.md](ISO20816-3机组分类与限值.md) 顶注）**不受影响**。
   但 GB/T 41850.1-2024 对应 ISO 20816-1【题】，可能已替代 GB/T 6075.1-2012【未核】。
2. ★**GB/T 41095-2021《机械振动 选择适当的机器振动标准的方法》**：讲的正是「这台机器该套哪本标准」。
   这和 vibration 1.3.0「适用与否由本模块判」（定案 §1.5.3）是同一件事，**建议取原文核对**。
3. ★**风电有专门的振动评价标准**：GB/T 35854-2018、ISO 10816-21:2015、NB/T 31129-2018 振动状态评价导则、
   NB/T 31004-2011 振动状态监测导则。风电机组不归 GB/T 6075.3 管，不能拿它的分区去判。
4. ★**工业机器人运维有成套国标 GB/T 42983.1~.4-2023**，四部分是在线监测、故障诊断、健康评估、预测性维护，
   与 `servo_health`（每个关节一条诊断）直接对口。
5. 伺服电机的标准（GB/T 7344、GB/T 30549、GB/T 16439 等）都是**产品技术条件**。
   它们有没有振动限值、限值是不是出厂试验口径，**要看原文**。
   在看原文之前，[小功率电机与伺服振动判级标准核对.md](小功率电机与伺服振动判级标准核对.md) 的结论「没有伺服现场判级标准」不变。
6. 光伏设备几乎**不涉及振动**。和 AI 相关的落在两处：**图像检测**（EL、红外、无人机巡检，对得上 `vision-infer` 那条线）
   和**性能数据诊断**（I-V 曲线、PR）。唯一的旋转件是跟踪支架的电机。
