## 4 原文的问题

### 4.1 状态监测只考漏报、不考误报

只有准确率与漏报率两项；漏报 40% 也算合格。异常样本少时，「全判正常」的准确率可以很高但漏报 100%，会被漏报率挡住；
反过来「多报」只受准确率约束。**若拿本标准作验收依据，宜另约误报率。**

### 4.2 附录 B.3 不确定性度量（资料性）自相矛盾

- 式 B.3：UQ = mean(1 − π)，π 是预测分布落入 [α⁻, α⁺] 的概率质量。预测越好 π → 1、UQ → 0；
  但原文写「UQ 值越接近于 1，算法稳定性越好」—— **方向反了**。
- α 定义为「0.05(EOL − tᵢ)」（时间量），又代进 α^± = r(tᵢ)·(1 ± α) 当无量纲系数用 —— **量纲对不上**。

### 4.3 附录 B.2 精确度（资料性）符号不一致

式 B.2 用 r*(tᵢ) − r(tᵢ) − M，M 为「误差的样本均值」；而式 11 的误差定义是 e = r − r*，方向相反。
照字面算，减的不是同一方向的均值，结果不是标准差。

### 4.4 式 17 SPE 是**相对误差版**，与 PHM 2008 原式不同

放大核对原文：

    SPE(tᵢ) = Σ [ e^( e(tᵢ) / (α·r(tᵢ)) ) − 1 ]      e(tᵢ) ≥ 0（过早）
              Σ [ e^( −e(tᵢ) / (β·r(tᵢ)) ) − 1 ]    e(tᵢ) < 0（过迟）
    α ∈ [10,15] 宜 13；β < α，宜 [7,12] 如 10

- 方向对：e = r − r* ≥ 0 即预测寿命短于实际（过早），除以较大的 α，罚得轻。
- ★分母多了 r(tᵢ)：同样 13、10 两个常数，在相对误差上量级完全不同 —— 相对误差 100% 过早只罚 e^(1/13) − 1 ≈ 0.08。
  **与 PHM 2008 公开榜单的分数不可比。**
- 记号小问题：左边写 SPE(tᵢ) 而右边是对 i 求和；求和上限写 n、他处写 N；β 与附录 D 的「误差权重因子 β」同名。

### 4.5 Ac 与 SPE 在寿命终点附近发散

式 12 Ac = mean(e^(−|e|/r)) 与式 17 都以 r(tᵢ) 作分母。越近寿命终点 r → 0，任何非零误差都使该样本 Ac 项 → 0、SPE 项 → ∞。
原文未规定终点附近的样本怎么处理。

### 4.6 60% 合格线有多松

若各样本相对误差同为 δ，则 Ac = e^(−δ)：Ac = 60% 对应 δ ≈ 51%，Ac = 90% 对应 δ ≈ 10.5%。
⇒ **平均相对误差五成左右也能过合格线。**

### 5.2 RUL 预研（`research/rul/README.md`）

- 附录 D「推荐群体基准」= 我方评测纪律里的**常数基线**；R² 本身就以均值预测器为零点，我方记的「比常数预测器还差」即 **R² < 0**。
- 附录 D 分级其实是**相对误差档**：令 r* = β·r，则 S_MAE(β) = (1 − β)·mean(r)，即
  MAE ≤ 平均真实 RUL 的 10% 优秀、20% 良好、30% 一般、40% 略差、超过为差；RMSE 同理（换成均方根）；
  S_R²(β) = 1 − (1 − β)²·Σr² / Σ(r − r̄)²。SPE 因不对称，取 β 与 2 − β 两端的均值作档界。
- 我方现只报 RMSE；可补 Ac / MAE / R² / SPE 并分级。★先定 §4.5 的终点处理 —— 我方目标是归一化剩余比例，终点 r = 0。
- 9.3 初级 / 高级：高级要求测试集含**训练集没有的失效模式**。FEMTO 不标失效模式 ⇒ **最多只能称初级**。
