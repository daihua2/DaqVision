## 0 结论

- ★**小电机、伺服的「无标准时区界」有了国标出处。** 附录 C 表 C.1 与此前网页抽取的 ISO 20816-1 表 C.1 **逐值相同**：
  A/B 0.71~4.5，B/C 1.8~9.3，C/D 4.5~14.7 mm/s（速度有效值）；注 2「小型机器（如功率不大于 15 kW 的电动机）倾向于取范围的下端」。
  按 `C-43`「有国标按国标」，[小功率电机与伺服振动判级标准核对.md](小功率电机与伺服振动判级标准核对.md) 改引本标准。
  **附录 C 是资料性**，原文要求「宜符合机器供应商和客户之间的商定」，下端值只是「倾向」，不是规定。
- **前言没有「代替 GB/T 6075.1」的说法。** 国标层面 GB/T 6075.1-2012（= ISO 10816-1:1995）与本标准目前**并存**。
  ISO 层面 20816-1 已取代 10816-1，国标未跟进声明。清单文档原写「可能已替代」，订正为「前言未写代替」。
- 前言列 GB/T 41850 已发布第 1、8、9 部分（截至 2024-12）；引言拟定第 1、2、4、5、8、9 部分，**没有第 3 部分**。
  ⇒ 判级依 GB/T 6075.3-2011 的决定不受影响。
- **§4.4.1 支持「只取径向判区」**：「在一个或两个径向方向上……测量一般就满足运行监测的要求。轴向振动的测量能作为测量的补充，但仅用于推力轴承的评价。」
  vibration 1.3.0 已改为只取径向判区（定案 §1.5.2），这是又一处出处。

## 1 与我方相关的条款

| 条款 | 原文要点 | 对我方 |
| --- | --- | --- |
| §4.1.3 注 1 | 以往验收宽带测量频率范围 10 Hz~1 000 Hz，「这也许不满足用于状态监测的要求」 | 传感器带宽口径；我方低频传感器的带宽未核 |
| §4.3.1 | 非旋转部件首选「均方根速度」，轴振动首选「峰峰位移」 | 与传感器口径惯例「速度 RMS、位移峰峰值」（定案 §1.5.1）一致 |
| §4.3.3 | 振动烈度 = 在额定支承和运行状态下测得的**最大**宽带量值 | 同我方取最大值 |
| §4.4.1 | 运行监测在一个或两个径向方向测量一般已够；轴向仅用于推力轴承 | 见 §0 |
| §4.6 | 「应在达到合同约定的正常运行工况……后进行」，其他状态的测量「不适用于根据第 6 章进行评价」 | 支持停机 / 非稳态时不判区 |
| §4.7 | 环境振动大于推荐限值的 1/3 时宜设法减小 | —— |
| §6.1.1 | 两种测量方法都适用时「通常应采用限制更严格的那一个」；准则**不适用于两倍线频**电磁振动 | 电机两倍线频成分会抬高总值，标量里分不开 |
| §6.3.2.1 | 速度足以表征宽范围转速的烈度，但「单一速度值……可能导致不可接受的大的振动位移。特别当 1 倍转速频率占主导时，对低速运转的机器尤其如此」 | 1.3.0 对 <600 r/min 的「可能判轻」警示有出处 |
| §6.3.2.3 | A 新投产；B 可不受限制地长期运行；C 不适合长期连续运行；D 足以造成损坏 | 同 GB/T 6075 |
| §6.3.2.4 注 | 「对没有明确国家或国际标准的机器，其非旋转部件的振动评价见附录 C」 | ★无标准设备的依据 |
| §6.3.2.5 | 区域边界「本身并不用作验收的技术指标」 | —— |
| §6.3.3 | 准则 II：振动量值变化，即使未到 C 区也要采取措施；比较须同位置、同方向、大致相同运行状态 | 与自训基线偏离同思路；比较条件对得上「本帧与基线不可比」的判定 |
| §6.4.2 | 报警值「通常与……经验确定的基线值有关」；没有基线时按同类机器经验或商定验收准则 | 支持自训基线；无基线时用自定门槛 |
| §6.4.3 | 停机值与机械品质有关，「通常与用于设置报警的稳态基线值无关」 | —— |
| 附录 B | 滚动轴承：加速度峰值、波峰因数、频率分析、冲击脉冲、包络等 | 我方标量里没有峰值加速度，**未核** |
| 附录 C.2 | 区界系数 Z_bound：A=1、B=2.56、C=6.4（以 A 区限值为 1） | 0.71 × 2.56 ≈ 1.8，0.71 × 6.4 ≈ 4.5 ⇒ 表 C.1 下端三值正是这组比例 |
| 附录 D | 矢量变化：总值从 3 降到 2.5 mm/s，矢量变化却是 5.2 mm/s | 只看总值会漏掉相位变化，标量做不到 |
