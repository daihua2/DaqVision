## 1 分层判据：一份实现该拆成三层看

| 层 | 是什么 | 与输入的关系 | 何时能拿 |
| --- | --- | --- | --- |
| **A 机制** | 打分怎么聚合、阈值怎么定、证据怎么组织、worker 怎么活 | ★**无关** | **现在** |
| **B 知识** | 专家经验（1× 主导=不平衡）、运维检查项 | 无关，但**要有对应输入才用得上** | 知识**现在**可入库，判据等 L2 |
| **C 实现** | 特征提取：读什么、算什么 | ★**强相关** | 等输入到位 |

**此前我方只看 C 层，一看「要波形」就整个否掉。**

## 2 ★现在就能拿的（A 层，逐条实测确认）

| # | 来源 | 是什么 | 我方现状 |
| --- | --- | --- | --- |
| A1 | `v5 rule_based_diagnoser.py` | ★**support / conflict 双向加权聚合**：支持证据加分、**反对证据扣分**，归一化成各类占比 | ★**我方完全没有「反对证据」这一格**，`iso_zone` 是单向判据 |
| A2 | 同上 `_rule_value()` | ★**软判据** `_clip01((v − 阈值) / 过渡带宽)` —— 判据在过渡带里**连续变化**，不是 0/1 跳变 | ★我方 `iso_zone` 是**硬分档**，值在边界抖，区就跳（外部项目 §6.6 记过这个病） |

| A4 | `v4 app.py::template_warning` | ★★**留一法定阈值**：从正常样本自己估「正常之间能差多远」，取 95 分位 × 可调系数 | ★**没有**。而它**只要正常样本、不要故障标签** —— 现场恰恰只有正常数据 |
| A5 | 同上 | `threshold_factor` —— **运维可调松紧**，不必改代码重训 | 没有 |
| A6 | 同上 | `distance_series` —— 回最近 60 帧的距离序列 ⇒ **趋势图直接能画** | 没有 |
| A7 | `v5 knn_case_retriever.py` | ★**案例检索机制**：z-score 标准化 → 欧氏距离 → top-k → **返回标签分布** | 没有。与第②层**互补**：②答「偏离多少」，它答「以前什么时候也这样过」 |
| A8 | `v5 evidence_builder.py` | ★**证据包四路合一**：规则 + 模型 + KNN + 专家卡 | 我方 README 列为第④层，**一直没做**，而结构是现成的 |

| A10 | `meter 各服务的 main_resident.py` + `main_non_resident_backup.py` | ★★**常驻 / 按需加载两种 worker 形态都实现了** | ★正是 [`推理编排与模型驻留.md`](推理编排与模型驻留.md) 还在定的事 —— **现成的取舍经验** |

★**A1~A3 全部可以直接套在我方现有的 13 个标量上**：
我方已有 `axial_ratio` / `vel_z_max` / `ratio_drift` / `temp_rise` / `iso_zone`，
完全可以定义我方自己的判据 id，用同一套 support/conflict 结构组织，**不需要任何新输入**。

★**A4 是这份清单里最有价值的一条**：它是一个**不需要故障标签的异常检测**，
而现场唯一有的就是正常数据。它与我方第②层是近亲 ——
②是「和基线 μ/σ 比」（隐含高斯假设），它是「和一组正常样本的最近邻距离比」（**不假设分布**）。
⇒ 但它**答不了「是哪一类故障」**，是第②层的**一般化**，不是第③层的替代品。

## 3 B 层：知识（现在可入库，判据等 L2）

`v5 expert_knowledge.py`（30 行）对五类各给三样：

| 字段 | 例 | 与输入的关系 |
| --- | --- | --- |
| `supports` | 「1X 主导」「1X 占比高」 | 要阶次 ⇒ 等 L2 |
| `weakens` | 「2X 与 3X 同时很高」 | 同上 |
| ★`recommended_checks` | 「检查转子质量分布」「检查联轴器对中」「检查地脚、底座和壳体紧固」 | ★★**完全无关，一行不用改** |

★**`recommended_checks` 是这套东西里最有现场价值的部分** ——
它把「结论」变成「该去做什么」，而且**现在就能挂到我方已有的结论上**
（比如 `direction_hint` 指向不对中时，直接给出那三条检查项）。

五张规则卡（`rule_cards_v2/*.yaml`）的 **support/conflict 组合与权重**属于 B 层：
结构现在能拿（A1），**内容等 L2 的 `_e_p1..p8` 到位**。

## 6 待用户定夺

   三样都**不需要任何新输入**，且都补的是现有短板；

   现在的准确说法是「**C 层等 L2，A 层现在就集成**」；
