## 0 结论

- ★**按标准分两段**：风机 **> 300 kW 或刚性支承**用 GB/T 6075.3（我方现行依据）；**≤ 300 kW**（配标准电机最大 355 kW）用 **ISO 14694**。
- ★**我方代码目前不分风机**：只要台账填了「第 2 组」，就按 GB/T 6075.3 的表判。对 ≤ 300 kW 风机这比 ISO 14694 **严得多**（见 §4），会把正常运行的风机判成警告甚至危险。
- 怎么改属方案，**未定**（§5）。

## 1 GB/T 6075.3-2011 / ISO 10816-3:2009 对风机的限制

第 1 章适用范围列有「blowers or fans」，注原文：

> the vibration criteria presented in this part of ISO 10816 are generally only applicable to fans with power ratings greater than 300 kW or fans which are not flexibly supported. … Until such time, classifications can be agreed between the manufacturer and the customer, using results of previous operational experience, see also ISO 14694.

## 2 ISO 14694:2003 Industrial fans — Specifications for balance quality and vibration levels

来源：全文（46 页，第一版 2003-03-15）。★**修订 Amd 1:2010 未取得**，其改动【未核】。

- **第 1 章**：适用于装机功率 **< 300 kW** 的各类风机（或配最大 355 kW 的标准电机）；更大的用 ISO 10816-3。不含纯循环风扇（吊扇、台扇）。只含刚性转子。优选参数为**速度 mm/s**；因各地习惯不同，**r.m.s. 与峰值都给**。
- **表 1 风机用途类别（BV）**（按用途 + 驱动功率）：住宅 ≤ 0.15 kW BV-1、> 0.15 kW BV-2；暖通与农业 ≤ 3.7 kW BV-2、> 3.7 kW BV-3；
  **工业过程与发电（布袋除尘、洗涤、矿井、输送、锅炉、助燃风、污染控制等）≤ 300 kW BV-3**，> 300 kW 见 ISO 10816-3；交通与船舶 ≤ 15 kW BV-3、> 15 kW BV-4；
  机车车辆 ≤ 75 kW BV-3、> 75 kW BV-4；石化工艺（有害气体）BV-4；地铁 / 隧道 ≤ 37 kW BV-3、> 37 kW BV-4；芯片洁净室 BV-5。
  注 2：空冷器、冷却塔用的大直径（2.8~12.5 m）轻型低速轴流风机为 BV-3。
- **§8.4 / 表 5 现场振动限值**（轴承座、filter-out 宽带，速度 mm/s；**r.m.s. 为优选值**，峰值是北美习惯、与 r.m.s. 无严格换算关系）：

| 状态 | 类别 | 刚性 r.m.s. | 柔性 r.m.s. | （刚性峰值 / 柔性峰值） |
| --- | --- | --- | --- | --- |
| 启动（Start-up） | BV-1 | 10 | 11.2 | 14.0 / 15.2 |
| | BV-2 | 5.6 | 9.0 | 7.6 / 12.7 |
| | **BV-3** | **4.5** | **6.3** | 6.4 / 8.8 |
| | BV-4 | 2.8 | 4.5 | 4.1 / 6.4 |
| | BV-5 | 1.8 | 2.8 | 2.5 / 4.1 |
| 报警（Alarm） | BV-1 | 10.6 | 14.0 | 15.2 / 19.1 |
| | BV-2 | 9.0 | 14.0 | 12.7 / 19.1 |
| | **BV-3** | **7.1** | **11.8** | 10.2 / 16.5 |
| | BV-4 | 4.5 | 7.1 | 6.4 / 10.2 |
| | BV-5 | 4.0 | 5.6 | 5.7 / 7.6 |
| 停机（Shutdown） | BV-1、BV-2 | 注 1 | 注 1 | —— |
| | **BV-3** | **9.0** | **12.5** | 12.7 / 17.8 |
| | BV-4 | 7.1 | 11.2 | 10.2 / 15.2 |
| | BV-5 | 5.6 | 7.1 | 7.6 / 10.2 |

  注 1：BV-1、BV-2 的停机值应按历史数据定。
- 原文对三档的说法：新投运应在「启动」值以下；随运行增长是合理的，未到「报警」都安全；到「报警」立即查因、限时运行；到「停机」立即处置或停机。
  ⇒ 结构是**三条线**，不是 A/B/C/D 四区。可近似对为：≤ 启动 ≈ A，启动~报警 ≈ B，报警~停机 ≈ C，> 停机 ≈ D（**此对应是我方推断，标准未如此表述**）。
- 原文：历史数据很重要，限值宜按每台风机的运行或历史数据评估与调整。

## 3 JB/T 8689-2014 通风机振动检测及其限值（行业标准）

来源：全文扫描件（9 页，逐页看图）。

- **第 1 章**：适用于离心式、轴流式、混流式通风机**出厂检验、型式试验和使用现场振动指标的验收**。
- §2.1：测量参数为**振动速度方均根值（有效值）**。
- **§3.1.2 限值（只有一条合格线）**：刚性支承 v_rms ≤ **4.6 mm/s**；挠性支撑 v_rms ≤ **7.1 mm/s**。
- §3.2：电机两端轴承或各轴承座测**垂直、水平、轴向**三向（电机带风扇罩时轴向可不测），取最大值；§3.3.2 仪器频率范围一般 **10 Hz~1 000 Hz**；§3.3.3 测量误差 ±10%。
- §3.5.3：变速风机在高、中、低三种转速下分别测，取最大值。§3.5.5：运转与不运转振动值之差应大于不运转时的 3 倍，否则认为有外界振动。
- 附录 A（资料性）：仪表无有效值功能时，可用速度峰值（刚性 ≤ 6.5、挠性 ≤ 10 mm/s）或位移峰峰值（刚性 ≤ 1.24×10⁵/n、挠性 ≤ 1.90×10⁵/n µm，n 为转速 r/min）。

## 4 ★与我方现行判法的差距（以工业过程风机 BV-3 为例）

| 支承 | 我方（GB/T 6075.3 第 2 组）A/B · B/C · C/D | ISO 14694 BV-3 启动 · 报警 · 停机 | JB/T 8689 合格线 |
| --- | --- | --- | --- |
| 刚性 | 1.4 · 2.8 · **4.5** | **4.5** · 7.1 · 9.0 | 4.6 |
| 柔性 | 2.3 · 4.5 · **7.1** | **6.3** · 11.8 · 12.5 | 7.1 |

⇒ 一台 ≤ 300 kW、刚性支承的工业风机振动 4.5 mm/s：ISO 14694 说「新投运可接受」，JB/T 8689 说「合格」，**我方判 C/D 交界（危险边缘）**。
柔性支承 7.0 mm/s：ISO 14694 在启动与报警之间（可长期运行），**我方判 C 区（警告）**。
