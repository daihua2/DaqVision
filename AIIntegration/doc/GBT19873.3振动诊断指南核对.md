## 0 结论

- ★**只靠总值标量分不清常见的安装类故障。**
  原文：「有很多和安装问题相关的故障可能会导致高的 1x 振动。在这些故障中包括不平衡、不对中、外壳变形、基础倾斜、滑座水平、管道应力和过大的轴承间隙。在这种情况下，需要在机器上进行特殊的振动测量，来描述该 1x 振动的本质，且区分不同的 1x 故障。这些测量包括：时域波形测量，相位测量和工作变形（ODS）测量。」（P16，已核）
  ⇒ vibration 的 13 标量随机森林分类（不平衡 / 不对中 / 松动 / 轴承……）**按本标准做不到**。
  10-08 用户定的「只报、不推检测状态」有了标准依据。输出措辞宜改为「疑似，需频谱 / 相位确认」，**待用户定，不先落码**。
- **方向性**：本标准**没有**轴向 / 径向幅值比的数值判据。
  不对中的判据是「跨联轴器 180° 相位改变」（相位，不是幅值比，表 B.1）。
  ⇒ vibration 的「方向性提示」只能标为经验判据，不能引用本标准。代码与文档里本来就写的是「经验判据，只作提示」，不用改。
- **引言**：「GB/T 19873 不界定振动限值」，限值在 GB/T 6075 / GB/T 11348（P4）。
- **基线**：§4.2「获取一系列工况和配置下的基线振动……是一个很好的实践」，同时记转速、负荷、压力、温度（P6）。
  我方基线不分工况，**负荷变化大的设备可能误报**，这一点值得在基线说明里写明。

## 1 表 B.1 安装故障的故障表（P20，已核）

| 故障 | 振动特性 | 其他描述符 |
| --- | --- | --- |
| 不对中 / 同轴度误差 | 1x 或 2x，有时 3x | 定向力、跨联轴器 180° 相位改变 |
| 松动 | 通常递减的运转速度谐波 | 使用相位辨别松动位置 |
| 轴承间隙 | 1x，伴随小的谐波分量 | 定向 |
| 管道压力 | 1x | 定向，时域波形削波 |
| 软脚 | 1x，加 2x 电源频率 | 软脚测试 |
| 碰摩 | 时域波形中的削波，旋转矢量（螺旋振动） | 可以产生反进动涡动 |
| 不平衡 | 1x | 跨联轴器 0° 相位改变 |
| 轴弯曲 | 1x 特别是在低速下 | 在特定的转速可以由不平衡抵消 |
| 壳体变形 | 1x，有时 2x | 从端到另一端 180° 相位改变 |
| 共振 | 在特定频率的高振动 | 共振测试提取固有频率 |
| 基础倾斜 / 滑座水平 | ODS 通常为 1x | ODS 中的摇摆运动 / 轻微倾斜 |

⇒ 区分各行要靠**相位、谐波族、波形**。我方只有「主频」一个峰，最多看出 1x、2x、0.5x 一类倍频，看不出谐波族与相位。

## 2 其他可借用的条款（子代理笔记，未逐字复核）

- **B.2.3**：「如果振动量值在允许限度内，那么这不是一个安装故障」（P15）。
  ⇒ 烈度在 A/B 区时，安装类故障分类可降级或不出。待定，不先落码。
- **表 A.1 第 5 步**：先查信号故障（零输出、零点漂移、不稳定的低频分量）（P9）。与「无可信输入不出 OK」同向。
- **表 A.1 第 10 步**：区分阶跃变化与渐变；第 19 步：1x 阶跃也可能是「仪器的变化」（P10~P11）。
  ⇒ 可借来区分「设备变了」和「换了传感器」。
- **表 D.1 滚动轴承**：类型 0（润滑缺陷）用宽带测量，「摩擦力在高频区域增加（主要在 8 kHz 倍频程带）」，润滑缺陷「会引起轴承温度升高」；类型 1~3 要用解调谱等（P32~P34）。
  ⇒ 温度可作润滑问题的旁证；8 kHz 一带我方低频传感器测不到。
- **图 D.1 / D.2**：峰值与 rms 加速度二维烈度图判轴承，需要 10 Hz~10 kHz 的峰值和 rms 两个量（P30~P31）。
  我方传感器的加速度是峰值还是 rms、带宽多少，**未核**，不能套用。图上区界数值子代理目测，2/3 区边界看不清。
- **第 7 章**：人工智能、模式识别「也是可以使用的」，但本部分重点是「基于经验的逻辑框架」（P8）。
- **第 8 章**：建议措施取决于诊断置信度，例如「该机器之前有没有正确地做过同样的诊断结论」（P8）。
