## 0 结论

- ★**第 1 部分 6.1 原文（已核）**：「电机的轴承缺陷、发热、不平衡等故障，由于受到机器结构和运行条件的限制难以直接通过上述参数信息进行识别，宜选择性地部署附加传感器采集对此类故障更加敏感的监测量。」
  「上述参数」指目标 / 实际转角、转速、转矩、电流等驱动器量。
  ⇒ `servo_health` 只用驱动器遥测判「轴承退化」，**与本标准的立场相反**。用的是「宜」字条款，不算违规；但**对外不能说「符合 GB/T 42983」**。
- **采样率**：
  - 总线方式（8.1.4）只写「应满足……性能要求」，**没给数字**。
  - 附加传感器（8.2.4）：振动「宜不低于 10 kHz」，电流、电压「宜不低于 1 kHz」。
  - 附录 A 表 A.1 建议驱动器和电机量「与驱动器 PWM 载波频率相同」。
  ⇒ 我方 10 Hz 不违反正文条款，但比建议值低几个数量级。
- **三部分都没有算法验收的准确率一类指标。** 唯一的数字门槛是第 3 部分判断矩阵的一致性比 CR < 0.1。
- **第 3 部分按关节拆成控制器、驱动器、伺服电机、减速器四个部件评估**（图 4），与 `servo_health`「每个关节一条诊断」吻合。

## 1 第 1 部分 在线监测（P5~P14）

| 条款 | 要点 |
| --- | --- |
| 6.1 伺服电机 | **应**测：目标转角 / 转速 / 转矩；实际转角及跟踪偏差、实际速度与方向、实际电流、抱闸状态、编码器电池电压。**宜**测：电机温度、电机振动（已核） |
| 6.2 驱动器 | **应**测：使能、控制模式、运行 / 通信 / 存储器状态、主回路电压电流、控制板电压、直流母线电压电流、功率模块温度、输出相电流 |
| 6.3 减速器 | **宜**测：振动 / 噪声、温度 |
| 8.1.4 | 总线方式为首选；采样率不给数字 |
| 8.1.5 / 8.2.5 | 按机器人**动作周期**组织数据：运动开始时开始采集，运动结束时停止 |
| 8.2.3 | 振动传感器装在电机驱动端支撑轴承的**径向**；按 GB/T 14412 刚性连接 |
| 8.2.4 | 振动 ≥10 kHz，电流 / 电压 ≥1 kHz，声发射 ≥1 MHz |
| 8.2.6 | 多通道**应**同步采样 |
| 8.2.7 | 数据保存：测量值与单位（**应**用国际单位制）、时间、位置、传感器类型、采样频率 / 模式 / 长度、系统精度 |

⇒ `servo_health` 是固定 20 s 滑窗、每 5 s 一次，**不对齐动作周期**。8.2.7 的元数据清单可补进模型导入时的「自述」要求。

## 2 第 2 部分 故障诊断（P5~P10）

- 流程（第 4 章）：在线监测 → 在线故障报警 → 离线测试诊断。
- **5.1 b) 残差报警**：「宜选用电流作为观测器输出参数，驱动器信号（转矩、转速、转角等）作为输入参数，使用电流残差值对电机进行在线故障报警」；阈值「宜选用正常运行下残差序列方差的 3 倍」（原文是「方差」，不是「3σ」）。
  ⇒ 只用驱动器量、不依赖外部模型，可作 `servo_health` 的确定性对照。
- **5.2 附加传感器特征**：电机振动用均方根值，温度用有效值 / 平均值；减速器振动用均方根值，声发射用能量。**不给阈值**。
- **6.3 离线诊断**：包络、谱、小波分析；人工智能宜选神经网络、支持向量机。
- **附录 A 表 A.1**（资料性）：18 项故障**全是驱动器 / 编码器自带报警**，例如：
  - 过载：一段时间内大于额定力矩 1.2 倍；
  - 过流：大于 2 倍；
  - 过速：超出指令值 12.5%，400 ms；
  - 驱动器过热：超过 95 ℃，1 s。
  **减速器、轴承、电机本体都没有判据。**

## 3 第 3 部分 健康评估（P7~P14）

- **表 1 三级**：完好 [80,100]、退化 [60,80)、故障 [0,60)。表 2 写作 [80,100)，两表不一致，以原文为准。
- **5.2 指标体系**：
  - 控制器**应**含转矩 / 位置 / 速度偏差；
  - 驱动器**应**含电压、电流、温度；
  - 伺服电机**宜**含转矩、电流、转速、振动；
  - 减速器**宜**含温度、声发射、振动。
- **6 基线**：
  - 「应在机器人出厂时做基线测试」；
  - 实时型指标：μ 为健康基线，μ±σ 为退化基线，μ±3σ 为故障基线，「可进行适当调整」；
  - 投产稳定后、作业较大变更或修复后**应**更新。
- **7 评分**：
  - 单指标按分段线性公式打分（式 3~5），超过 100 取 100；
  - 多指标用 AHP 判断矩阵求权重加权（式 6、7，附录 A，CR < 0.1）。
  - 原文**没定义**故障区（x 超过 μ±3σ）怎么算分。
- 附录 A 的 RI 表在 n=7 处印的是 1.23，常见值 1.32，疑印误（子代理所见，未复核）。

⇒ 健康分是「对基线的偏离」，**不是分类概率**。若把 `servo_health` 的「轴承退化」概率换算成健康分，那是我方自定，要写明不是国标口径。
⇒ μ±σ / μ±3σ 可作「无适用标准时自定门槛」的方法出处（vibration 1.3.0 的自定门槛现在由用户手填）。
